# **App Name**: CampusConnect

## Core Features:

- News and Announcements Feed: A dynamic feed to display the latest school news and important announcements.
- Interactive School Calendar: An interactive calendar displaying school events, holidays, and important dates.
- Staff Directory: A comprehensive staff directory with contact information for teachers and staff members.
- About Us Section: Detailed information about the school's mission, values, and history.
- Accessibility Options: Adjustable font sizes, color contrasts, and keyboard navigation for improved accessibility.

## Style Guidelines:

- Primary color: Soft blue (#A0C4FF) for a welcoming and calming feel.
- Background color: Off-white (#F0F8FF) to provide a clean and modern backdrop.
- Accent color: Darker blue (#75A3D9) for interactive elements and highlights.
- Body and headline font: 'PT Sans', a humanist sans-serif, provides a blend of modernity and warmth, suitable for both headlines and body text ensuring readability.
- Clean, modern layout with a focus on readability and easy navigation. Ample white space to avoid clutter.
- Simple, clear icons to represent different sections and functions. Use a consistent style that complements the overall design.
- Subtle animations for transitions and interactive elements to enhance user experience without being distracting.
